# @allons-y/webcdoc

## 0.1.0

### Minor Changes

-   First release of the WebC documentation parser: `@allons-y/webcdoc` reads JSDoc-style comments in `.webc` files into JSON records with a `webcdoc` CLI and a Custom Elements Manifest adapter, and `@allons-y/webcdoc-schema` publishes the record types and JSON Schema. (📝 [#2](https://github.com/allonsy-studio/webc-docs/pull/2)) — thanks [@castastrophe](https://github.com/castastrophe)!

First release of the WebC documentation parser: `@allons-y/webcdoc` reads JSDoc-style comments in `.webc` files into JSON records with a `webcdoc` CLI and a Custom Elements Manifest adapter, and `@allons-y/webcdoc-schema` publishes the record types and JSON Schema.
